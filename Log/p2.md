主循环

```c++
while (window.ProcessMessages()) {     // 处理消息,关窗口时返回 false
    fb.Clear(MakeColor(30, 30, 30));   // 1. 清屏
    /* 2. 往 fb 里画像素 ... */
    window.Present(fb);                 // 3. 一次性上屏
}
```

## Core/Framebuffer.h 

1. 整块填充API  Clear(uint32_t color)
2. 单像素写入API  SetPixel(int x, int y, uint32_t color)
3. static uint32_t MakeColor(int r, int g, int b)——外部传入rgb，转化成0xRRGGBB格式
4. std::vector<uint32_t> m_pixels存储像素数据

## Core/Window.h Core/Window.cpp

1. 构造函数：注册窗口类、创建窗口（调整大小），填BITMAPINFO，m_bmi.bmiHeader.biBitCount = 32设置像素位数
2. ProcessMessages：处理本帧累积的所有Windows消息，返回是否收到退出消息
3. Present：把帧缓冲的内容显示到窗口上
4. WndProc：窗口过程函数
