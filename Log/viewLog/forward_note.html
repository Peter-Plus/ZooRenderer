约定：θ = yaw（绕 Y 轴左右转）、α = pitch（上下俯仰），基准朝向为 −Z。整套公式本质上是「先竖直拆，再水平拆」的两步正交投影。

分量公式

x=sin θ · cos α
y=sin α
z=−cos θ · cos α
θ = yaw，α = pitch。|Forward| = √(x²+y²+z²) = 1，天然为单位向量。

源码对照

Vector3 Forward() const {
    return Vector3(
        std::sin(yaw) * std::cos(pitch),   // x
        std::sin(pitch),                // y
        -std::cos(yaw) * std::cos(pitch)   // z
    ).Normalized();
}
关于 Normalized()： 数学上 (x,y,z) 已是单位向量，调用归一化主要是防浮点误差累积，逻辑上可省。
关于 −Z： 当 yaw=0、pitch=0 时 Forward=(0,0,−1)，即默认看向 −Z，这是右手系（OpenGL 风格）的常见取向。
